## Что есть в продукте

- Очередь до 99 текстовых, графических и файловых элементов; последовательная
  вставка в порядке очереди, ручное изменение порядка, удаление и очистка.
- Два экрана popover: очередь и Settings. В настройках — переназначение двух
  глобальных сочетаний, выбор одного из 7 языков и Launch at Login.
- «Объединить и вставить…» для минимум двух текстовых элементов: шесть вариантов
  разделителя, включая пользовательский, короткое превью и одна команда ⌘V
  с полным объединённым текстом. Превью защищено сравнением ID очереди.
  Последний успешно применённый разделитель хранится в UserDefaults.
- Выход с экрана подтверждения или закрытие popover отменяет ожидающую
  пакетную вставку. При ошибке после перехода к приложению получателя popover
  снова получает фокус и показывает причину. Очередь расходуется лишь после
  `commandPosted`; это не подтверждение фактической вставки в чужое приложение.
- Полный 14-дневный триал начинается при первом запуске и хранится в Keychain.
  После истечения popover показывает активацию; очередь и данные пользователя
  сохраняются. Одноразовые напоминания появляются за 7, 3 и 1 день.
- Активация, проверка и деактивация текущего Mac подключены к публичному Lemon
  Squeezy License API. Приложение сверяет store/product/variant, хранит ключ и
  instance ID в Keychain, сохраняет платный доступ при временной ошибке сети и
  повторно проверяет лицензию раз в 7 дней даже без перезапуска. Ошибка чтения
  лицензии из Keychain не блокирует доступ и повторяется при следующем
  действии. Если сервер вернул неактивный ключ, созданный instance сразу
  освобождается. После временной
  ошибки проверка повторяется через 6 часов. IDs и checkout задаются
  build-настройками `LEMON_SQUEEZY_*` в `project.yml`: Debug — тестовый продукт,
  Release — live-продукт (Product 1379630, Variant 2155206); `archive` падает,
  если какое-то значение пустое.
- Sparkle 2.10.0 подключён через Swift Package Manager. Автоматические проверки,
  загрузка и установка включены без отдельной кнопки или пользовательских
  переключателей. Публичный EdDSA-ключ встроен, а пустой production
  `appcast.xml` читается из публичной ветки `main` и пока означает «обновлений
  нет».
- Немецкая локализация обращается к пользователю на «du», как сайт и
  немецкие тексты Apple: восемь строк лицензии и триала, остававшихся на
  «Sie», исправлены 26 сентября (`2fd305d`). Правило записано в `CLAUDE.md`.
- Заголовок, разделители и список обновлены: при пустой очереди остаётся один
  разделитель, немецкий счётчик визуально разбит на две строки, прокрутка и
  подсветка строк имеют отдельные настраиваемые отступы. Изменение UI после
  последней ручной приёмки нужно подтвердить на финальной сборке.

## Доказанная проверка

25 сентября на коммите `2647a5d` (дерево совпадает с merge `c0d5dd8` в
`main`) полный `VantoTests` прошёл: **100 тестов, 0 ошибок**. Команда:

```sh
xcodebuild test -scheme Vanto -destination 'platform=macOS,arch=arm64' \
  -only-testing:VantoTests \
  -derivedDataPath /private/tmp/VantoDerivedData \
  CODE_SIGNING_ALLOWED=NO
```

26 сентября дерево хотфикса `2fd305d` (немецкий «du») снова прошло полный
`VantoTests`: **100 тестов, 0 ошибок**; в собранном `de.lproj` не осталось
обращений на «Sie». GitHub CI на `main` зелёный для `977da3c` и `2fd305d`.

`CODE_SIGNING_ALLOWED=NO` применялось только к локальному тестированию. Эти
тесты покрывают модель, сепараторы, настройки, триал, лицензию, конфигурацию
Sparkle и отказные сценарии; они не
проверяют реальное переключение фокуса, вставку в другое приложение, VoiceOver,
подпись или установку. Полный ручной список — в `README.md`.

Неподписанная проверочная Release-сборка на этой же машине завершилась
`BUILD SUCCEEDED`: исполняемый файл `arm64`, Info.plist содержит версию
`0.1 (1)`, live-значения `LemonSqueezy*` и
`LSApplicationCategoryType = public.app-category.utilities`. Отдельно
проверено, что `archive` с пустыми `LEMON_SQUEEZY_*` завершается ошибкой. Команда использовала `CODE_SIGNING_ALLOWED=NO`, поэтому полученный
app имеет ad-hoc подпись и **не является** дистрибутивом. Эта проверка не
доказывает работу Hardened Runtime после Developer ID подписи.

## Текущее состояние выпуска

- Для первого выпуска выбран прямой download с сайта и только Apple Silicon.
  `project.yml` задаёт версию **0.1**, build **1**, macOS **13.0**. После
  `xcodegen generate` вычисленная Release-конфигурация:
  `ARCHS = arm64`, `ENABLE_HARDENED_RUNTIME = YES`,
  `ENABLE_APP_SANDBOX = NO`. Debug сохраняет Hardened Runtime выключенным.
  Проект использует автоматическую подпись.
- **25 сентября 2026:** `security find-identity -v -p codesigning` нашёл на
  этом Mac **0 valid identities**, включая 0 Developer ID Application. Это
  снимок данного хоста, не вывод о статусе учётной записи Apple. Developer ID
  подпись и нотарификация сейчас не выполнены.
- `dist/` игнорируется Git и содержит исторический dev-артефакт; он не является
  кандидатом для покупателей. Новый подписанный и нотарифицированный контейнер
  ещё не собран и не проверен через Gatekeeper.
- **25 сентября 2026:** сайт, домен и почта готовы. Куплен домен
  `slenbder.com`, DNS — в Cloudflare. Сайт (`Site/` в репозитории) задеплоен
  на `https://vanto.slenbder.com` через Cloudflare Pages (production branch
  `main`, output directory `Site`; каждый мерж в `main` переразворачивает
  сайт автоматически). На сайте есть `/privacy`, `/terms`, `/refunds` и
  кастомная `/404`, плюс security-заголовки через `Site/_headers`. Кнопка
  «Visit our website» в `SettingsMenu.swift` ведёт на этот адрес (заменён
  старый временный `pastequeue-first-look.slenbder.chatgpt.site`). Почта
  `vanto@slenbder.com` и `hello@slenbder.com` работает на iCloud+ Custom
  Email Domain; SPF, DKIM и DMARC подтверждены как `pass` в заголовках
  реального письма, принятого Gmail. Первое тестовое письмо с пустым телом
  попало в спам из-за отсутствия репутации нового домена, а не из-за
  аутентификации — это ожидаемо и должно пройти после нескольких обычных
  писем. ChatGPT Sites (прежний хостинг того же сайта) больше не источник
  истины и может быть выключен.
- Тестовые Store ID, Product ID, Variant ID и checkout Lemon Squeezy проверены
  реальной тестовой активацией с лимитом 3 устройства. Live-продукт
  (Store 480340, Product 1379630, Variant 2155206, лимит 3 устройства по
  словам владельца) прописан в Release, но live-покупка через приложение ещё
  не пройдена. Вьетнамский банковский счёт в VND добавлен и выбран в Payouts,
  налоговая информация отображается как `Submitted`; первая фактическая
  выплата ещё не подтверждена. Политика приватности, условия использования и
  политика возврата опубликованы на сайте (`/privacy`, `/terms`, `/refunds`);
  канал поддержки — `vanto@slenbder.com`. Доставка ключа через реальную
  live-покупку и release notes ещё не готовы. Цена утверждена: $14.99.
- **26 сентября 2026:** на сайт подключена аналитика. Umami (cookieless,
  регион ЕС) считает визиты и события через прокси `functions/u/` на своём же
  домене; Microsoft Clarity (записи сессий, тепловые карты) грузится только
  после согласия в cookie-баннере. Обе цели, `Хотят скачать`/`Хотят
  купить`/`Прошли демо`/`Хотят написать`, и воронка `Демо → скачать`
  настроены и проверены живыми тестовыми событиями. `Site/privacy.html`
  описывает оба сервиса.
- **26 сентября 2026:** сайт работает на 7 языках приложения: английский в
  корне, `/de/`, `/es/`, `/pt-br/`, `/ru/`, `/ja/`, `/zh-hans/`, с
  переключателем в шапке и списком в футере, `hreflang`, `sitemap.xml` и
  `robots.txt`. Страницы собираются из `site-src/` скриптом
  `scripts/build-site.mjs`; результат коммитится. Первый заход на `/`
  один раз переводит на язык браузера, ручной выбор запоминается.
  Юридические страницы остаются на английском с переведённым примечанием.
  Проверено на превью Cloudflare Pages: адреса, редирект `/ru` → `/ru/`,
  локализованная 404. Переводы сделаны без вычитки носителями — её стоит
  провести до публикации, в первую очередь для японского и китайского.
  Заголовок вкладки главной страницы — просто «Vanto».
- Приватный Sparkle EdDSA-ключ хранится в локальном Keychain в записи
  `com.slenbder.vanto`; защищённая резервная копия ещё не сделана.
- `.github/workflows/ci.yml` проверяет PR и push в `main` на Apple Silicon:
  пересоздаёт проект, требует отсутствия diff в Xcode project и Info.plist,
  запускает XCTest и компилирует Release без подписи. Этот workflow не
  публикует артефакты. Первый удалённый прогон на push merge-коммита лицензии
  (run `36050938552`) и прогон текущего документационного merge `e2fd0c6`
  (run `36052254879`) завершились **success**. С 26 сентября второй job
  `Site build is current` пересобирает сайт и падает, если закоммиченный
  `Site/` устарел.
- **26 сентября 2026:** `main` защищён ruleset'ом `main` (active): запрет
  удаления и force push, изменения только через PR (0 одобрений), перед merge
  обязательны `Test and build` и `Site build is current`. Роль Repository
  admin может обойти правила — только для осознанного хотфикса. GitHub
  «AI Scan for pull requests» выключен: он падал на каждом PR с ошибкой
  неподдерживаемой модели.

## Ворота до публикации

1. **Выполнено:** выбран прямой сайт и arm64; Release-конфигурация включает
   Hardened Runtime. App Sandbox остаётся выключенным. До распространения
   по-прежнему требуются Developer ID Application, secure timestamp,
   notarization и stapling. Mac App Store — отдельный непроверенный путь.
   См. [документацию Apple](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution).
2. **Частично выполнено:** `project.yml` обновлён, проект сгенерирован,
   вычисленные Release-настройки сверены, Sparkle, production feed и live-ID
   Lemon Squeezy подключены, ветка влита в `main` с зелёным CI.
   Далее собрать Archive и экспортировать точный кандидат. Версию/build
   увеличить перед следующим публичным кандидатом.
3. На точном кандидате выполнить полный XCTest и ручной checklist из README:
   Accessibility с чистым разрешением, горячие клавиши, смешанный FIFO,
   файлы/изображения, пакетная вставка с отменой и ошибкой, оба экрана,
   VoiceOver, 99 элементов, локализации, Launch at Login после входа в систему,
   светлое/тёмное меню, триал и напоминания, экран после истечения, активация,
   деактивация, тихое обновление. Проверить поддерживаемую версию macOS и
   чистый Mac.
4. Для прямого канала подписать правильным сертификатом, нотарифицировать и
   прикрепить ticket к распространяемому контейнеру. Проверить подпись,
   архитектуру, entitlements, версию, notarization и Gatekeeper именно на этом
   контейнере; не переносить выводы со старого DMG.
5. **Частично выполнено:** live IDs и checkout Lemon Squeezy заполнены в
   `project.yml`, вьетнамский счёт добавлен и выбран для выплат. Осталось
   подтвердить первую выплату и пройти live-покупку,
   доставку ключа, три активации, деактивацию и возврат. Добавить ссылку помощи
   на экран истёкшего триала.
6. **Выполнено:** сайт, домен, почта и юридические тексты готовы
   (`https://vanto.slenbder.com`, `vanto@slenbder.com`, `/privacy`, `/terms`,
   `/refunds`). Ссылка в Settings заменена на настоящий адрес. Сайт переведён
   на 7 языков приложения. Осталось согласовать release notes и саму
   публикацию, а также вычитать переводы сайта носителями языков.
7. После загрузки проверенного подписанного артефакта подписать его Sparkle
   EdDSA-ключом и только затем добавить версию в production `appcast.xml`.
   Проверить реальное обновление с предыдущей установленной версии.
